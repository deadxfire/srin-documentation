Installation & Quickstart

Getting started with Srin Engine is rapid and straightforward. Follow this guide to set up your environment, clone the project, configure your environment variables, and start the local development server.

Server Requirements

Srin Engine is built to be lean and dependency-light, but requires modern PHP capabilities. Before installing, ensure your environment meets the following requirements:

  • PHP 8.1 or higher (PHP 8.2+ recommended)
  • PDO PHP Extension (along with pdo_sqlite, pdo_mysql, or pdo_pgsql)
  • OpenSSL PHP Extension (for encryption, secure session tokens, and CSRF)
  • Mbstring PHP Extension (for multibyte string processing)
  • Composer (optional, for autoloading and dependency management)

Installing Srin Engine

Option 1: Using Composer (Recommended)

Create a fresh Srin Engine application using Composer:

Bash 
composer create-project deadxfire/srin my-srin-app

Option 2: Cloning from GitHub

Alternatively, clone the repository directly from GitHub:

Bash 
git clone https://github.com/deadxfire/srin.git my-srin-app
cd my-srin-app
composer install

Environment Configuration

Srin uses a root .env file to manage sensitive and environment-specific configuration values. When you clone the project, copy the template file:

Bash 
# Linux / macOS
cp .env.example .env

# Windows PowerShell
copy .env.example .env

Open .env in your code editor. Here is a typical configuration:

INI / .env 
APP_NAME="Srin Engine"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://localhost:8000
APP_KEY=base64:srin-random-secret-key-32-chars

# Database Configuration (sqlite, mysql, or pgsql)
DB_CONNECTION=sqlite
DB_DATABASE=Storage/database.sqlite

# Or for MySQL:
# DB_CONNECTION=mysql
# DB_HOST=127.0.0.1
# DB_PORT=3306
# DB_DATABASE=srin_db
# DB_USERNAME=root
# DB_PASSWORD=secret
Production Notice

In production environments, always set APP_ENV=production and APP_DEBUG=false. This prevents internal stack traces from being displayed to end users and routes fatal errors to custom Pages/errors/500.srin.php views.

Directory Permissions

Ensure that the Storage/ directory is writable by your web server or CLI user:

Bash 
chmod -R 775 Storage

Starting the Development Server

Srin Engine comes bundled with a dedicated CLI utility (srin). You can launch the built-in development server with a single command:

Bash 
php srin serve

By default, the server starts at http://127.0.0.1:8000. You can customize the host and port:

Bash 
php srin serve --port=9000 --host=0.0.0.0

Directory Structure Overview

The Srin directory layout is clean, organized, and intentional:

Tree 
srin-app/
├── Config/           # Application, database, mailer & auth configuration
├── Controller/       # HTTP Controllers handling incoming requests
├── Core/             # Srin Engine core kernel, router, query builder, ORM
├── Database/
│   ├── Migrations/   # Database schema migrations
│   └── Seeders/      # Database test data seeders
├── Model/            # ActiveRecord Model classes
├── Pages/            # View templates (*.srin.php) & layouts
│   ├── errors/       # Custom 404, 419, 500 error pages
│   └── layouts/      # Master layout templates (@Connect)
├── Public/           # Web server document root (index.php, CSS, JS, images)
│   ├── assets/       # Static public assets
│   └── index.php     # Front controller & entry point
├── Routes/
│   ├── api.php       # Stateless API routes
│   └── web.php       # Web routes with session & CSRF protection
├── Storage/          # Local SQLite DB, logs, file cache, and uploads
├── .env              # Environment-specific credentials
├── composer.json     # Project dependencies and PSR-4 autoloading
└── srin              # Srin CLI console executable
