Introduction & Philosophy

Srin Engine is a high-performance, standalone PHP web framework built for developers who crave elegance, speed, and zero boilerplate. Engineered from the ground up by Arindam Makar, it provides an expressive syntax that feels natural, intuitive, and modern.

The Srin Philosophy

Modern web development often drowns in excessive configuration, bloated vendor folders, and redundant lines of boilerplate code. Simple tasks like reading an input query, filtering a database query, or returning distinct categories frequently demand 20 to 40 lines of repetitive ceremony.

Srin Engine challenges this status quo. Every subsystem in Srin is engineered around one core goal: maximum developer velocity with minimum code clutter.

The Srin Principle

If a common developer task takes 10 lines of code in other frameworks, Srin aims to make it expressive, clean, and achievable in 2 to 3 lines—without sacrificing type safety or database efficiency.

The Standalone Evolution: Zero Laravel Copycat

Instead of cloning traditional Laravel patterns (like verbose where()->where()->get(), findOrFail(), create(), and 20-line form request ceremonies), Srin Engine introduces its own clean signature style:

Traditional Verb (Copied) Srin Signature Verb (Unique) Why It Is Superior
where('a', 1)->where('b', 2)->get() fetch(['a' => 1, 'b' => 2]) Pass criteria array directly without verbose method chaining.
where('slug', $s)->firstOrFail() one(['slug' => $s]) Fetches record or automatically aborts with custom 404 page.
findOrFail($id) pick($id) Clean, concise model retriever with auto-404.
create($data) insert($data) Direct, intuitive persistence verb.
find($id)->update($data) modify($id, $data) Update records in one single atomic call.
destroy($id) remove($id) Expressive deletion verb.
$item->views += 1; $item->save(); $item->hit('views') Atomic counter increment and save in one method.
15+ lines of CSRF, honeypot, onlyInputs, and validate $data = $this->guard([...]) Defeats bots, enforces CSRF, validates fields, and auto-redirects on error in one line.
flash('success', ...)->redirectToRoute(...) $this->success(...)->go(...) Fluid, natural chaining.

The Standalone Evolution: Before & After

Consider a standard real-world controller action: reading a search string and category filter from the query parameters, querying published posts with eager-loaded comments, paginating, preserving query strings, and fetching distinct categories for the filter dropdown.

Traditional Framework Boilerplate (35+ Lines)

PHP (Verbose Style) 
public function index(): string
{
    $search = trim((string) $this->input('q', ''));
    $category = trim((string) $this->input('category', ''));

    $query = Post::where('is_published', true)->with('comments');

    if ($category !== '') {
        $query->where('category', $category);
    }

    if ($search !== '') {
        $query->where('title', 'LIKE', "%{$search}%");
    }

    $posts = $query->latest()->paginate(4);

    if ($search !== '' || $category !== '') {
        $posts->appends([
            'q'        => $search,
            'category' => $category,
        ]);
    }

    // Get distinct categories
    $allPosts = Post::where('is_published', true)->get();
    $categories = array_values(array_unique(array_filter(array_map(fn($p) => $p->category, $allPosts))));

    return $this->render('blog/index', [
        'title'          => 'Explore Srin Engine Blog',
        'posts'          => $posts,
        'categories'     => $categories,
        'activeCategory' => $category,
        'searchQuery'    => $search,
        'totalPosts'     => count($allPosts),
    ]);
}

The Srin Standalone Way (12 Clean Lines)

With Srin Engine's standalone superpowers—including $this->get(), $query->filter(), $query->search(), auto-retaining paginators, and native distinctValues()—the exact same action becomes pure poetry:

PHP (Srin Engine Standalone Style) 
public function index(): string
{
    $posts = Post::where('is_published', true)
        ->with('comments')
        ->filter('category', $this->get('category'))
        ->search('title', $this->get('q'))
        ->latest()
        ->paginate(4);

    return $this->view('blog/index', [
        'title'          => 'Explore Srin Engine Blog',
        'posts'          => $posts,
        'categories'     => Post::where('is_published', true)->distinctValues('category'),
        'activeCategory' => $this->get('category'),
        'searchQuery'    => $this->get('q'),
        'totalPosts'     => Post::where('is_published', true)->count(),
    ]);
}

Core Framework Architecture

Srin is structured cleanly into dedicated modules that operate independently or in harmony:

⚡
Ultra-Fast Routing
Dynamic route matching with parameterized wildcards ({id}, {slug}), named routes, and route-aware navigation helpers.
💾
ActiveRecord & Fluent Query
ActiveRecord models with fillable mass-assignment protection, relationships (hasMany, belongsTo), and fluent query chaining.
🎨
.srin.php Template Engine
Zero-overhead template compiler supporting @Connect layouts, @contentConnect sections, http://localhost:8000/assets/, and CSRF directives.
🛡
Defense-in-Depth Security
Built-in token CSRF verification, anti-bot honeypot traps, IP-based rate limiting, and safe HTML sanitization.
🛠
Srin CLI Artisan
A unified console companion to scaffold controllers, models, migrations, run migrations, and launch local development servers.
🚀
Lightweight Footprint
Boots in sub-milliseconds without heavy runtime dependency graphs. Perfect for production microservices and full-stack web portals.
