Global Helpers Reference

Srin Engine provides a rich collection of global helper functions that simplify common operations like reading environment variables, generating URLs, issuing redirects, running queries, flash messaging, and HTML escaping.

Helper Reference by Category

1. Configuration & Environment

Helper Return Description & Example
env(string $key, mixed $default = null) mixed Reads an environment variable from .env with automatic boolean, null, and empty string casting.
$debug = env('APP_DEBUG', false);
config(?string $key = null, mixed $default = null) mixed Reads a value from Config/*.php using dot notation. If key omitted, returns all Config/app.php settings.
$driver = config('database.default');
srin(?string $service = null) mixed Resolves a service from the dynamic container or provides microsecond benchmarking.
$mailer = srin('mailer');
$bench = srin()->bench(); // ['elapsed' => '1.8 ms', 'memory' => '2.1 MB']

2. URL, Routing & Assets

Helper Return Description & Example
getlink(string $path, mixed $handler, ?string $name = null) / getLink() \Core\Route Registers a GET route link in Routes/web.php.
getlink('/about', 'HomeController@about')->name('about');
postlink(string $path, mixed $handler, ?string $name = null) / postLink() \Core\Route Registers a POST route link in Routes/web.php.
postlink('/contact', 'ContactController@send')->name('contact.send');
putlink() / deletelink() / patchlink() / optionslink() / anylink() \Core\Route Registers route links responding to corresponding HTTP verbs or any verb.
grouplink(array $attributes, Closure $callback) / groupLink() void Registers a group of route links sharing attributes (prefix, checkpoint, name).
grouplink(['prefix' => '/admin', 'checkpoint' => 'auth'], function() { ... });
asset(string $path = '') string Generates a direct, absolute web URL to an asset. Automatically resolves image file extensions directly into assets/images/.
<img src="http://localhost:8000/assets/images/logo.png">
route(string $name, array|string|int $params = []) string Resolves the full URL for a registered named route.
$url = route('docs.show', ['topic' => 'controllers']);
url(string $path = '') string Generates an application URL aware of reverse proxies and subdirectories.
$url = url('/pricing');
app_origin() string Retrieves the current application origin (scheme + host + port).
$origin = app_origin(); // https://example.com
is_home() bool Returns true if the current request is the homepage (/).
is_route(string|array $patterns) bool Tests if the current route matches a name or wildcard pattern (e.g. docs.*).
is_route_active(string|array $patterns, string $class = 'active') string Returns CSS class name if active, empty string otherwise.
<a class="">Docs</a>
request_uri() / request_path() string Returns the current relative path without query strings.

3. Response, Views & Redirection

Helper Return Description & Example
view(string $page, array $data = []) string Renders a Pages/{$page}.srin.php template with bound data.
redirect(string $url, int $status = 302) void Issues an HTTP redirect header with CRLF injection protection.
back(int $status = 302, string $fallback = '/') void Redirects back to the previous page (HTTP_REFERER).
json(mixed $data, int $status = 200) void Sends a JSON response header and payload, terminating execution.
abort(int $code = 404, string $message = '') void Aborts execution and renders the matching error template in Pages/errors/{$code}.srin.php.
download(string $assetPath, ?string $downloadName = null) void Streams a secure file download from the assets/ folder.
e(?string $value) string Safe HTML entity escaping (XSS prevention).
auth() ?object Returns the currently authenticated user model instance.
auth_check() bool Returns true if the visitor is signed in.
auth_id() ?int Returns the authenticated user's ID.
auth_guest() bool Returns true if the visitor is a guest (not signed in).
hash_password($pwd) string Hashes a plain password using modern Argon2id with application peppering.
verify_password($pwd, $h) bool Constant-time verification of password against stored hash.
encrypt($val) string Hardware-accelerated AES-256-GCM authenticated symmetric encryption.
decrypt($payload) ?string Decrypts AEAD payload; returns null if forged, tampered, or invalid.

4. Database & Queries

Helper Return Description & Example
db(?string $table = null) QueryBuilder|Database If a table name is passed, returns a fluent QueryBuilder instance.
$posts = db('posts')->latest()->get();
If called without arguments, acts as a database query gateway:
$count = db()->scalar("SELECT COUNT(*) FROM users");

5. Security & Sessions

Helper Return Description & Example
csrf_token() string Retrieves or generates the active CSRF session token.
csrf_field() string Generates <input type="hidden" name="_csrf" value="..."> HTML.
csrf_verify(?string $token = null) bool Verifies submitted CSRF token using constant-time comparison.
honeypot_field(string $name = '_srin_hp_check') string Generates invisible anti-bot honeypot HTML markup.
honeypot_verify(string $name = '_srin_hp_check') bool Validates that honeypot field was left blank by human visitor.
rate_limit(string $key, int $max = 5, int $decaySeconds = 60) bool Checks if the current IP has exceeded the specified rate limit.
flash(string $key, ?string $message = null) ?string Sets or retrieves (and unsets) a one-time session flash notification.
flash('success', 'Post saved!');
$msg = flash('success');
has_flash(string $key) bool Checks if a flash key is currently present in the session without deleting it.
old(string $key, string $default = '') string Retrieves input value flashed from previous failed form submission.
auth(?string $guard = null) Core\Auth|Model\Account|null Accesses the authentication manager, or returns the authenticated account instance if logged in.
$user = auth();
auth_check(?string $guard = null) bool Quickly checks if visitor is authenticated.
if (auth_check()) { ... }
auth_id(?string $guard = null) int|string|null Retrieves the primary key ID of the currently logged-in account.
auth_account(?string $guard = null) ?Model\Account Retrieves the currently authenticated account model instance, or null.
hash_password(string $password, ?string $algo = null, array $options = []) string Hashes plain-text password using the powerful, memory-hard Argon2id algorithm (RFC 9106) with HMAC-SHA256 peppering.
$hash = hash_password($request->input('password'));
verify_password(string $password, string $hash) bool Constant-time, timing-attack safe verification of a plain-text password against a stored cryptographic hash.
if (verify_password($pass, $user->password)) { ... }
encrypt(string $value, ?string $key = null) string Encrypts a string using military-grade AES-256-GCM authenticated encryption with a unique 96-bit IV and 128-bit authentication tag.
$secret = encrypt('api-access-token-12345');
decrypt(string $payload, ?string $key = null) ?string Decrypts an AES-256-GCM authenticated payload. Verifies the AEAD authentication tag and returns null if ciphertext was modified or forged.
$token = decrypt($secret);

6. Logging & Diagnostics

Helper Return Description & Example
log_info(string $message, array $context = []) void Writes an informational entry to Others/logs/srin.log with timestamp and optional context JSON.
log_info('Order placed successfully', ['order_id' => 124]);
log_error(string $message, array $context = []) void Records an application error or exception.
log_error('Payment gateway connection timed out', ['gateway' => 'stripe']);
log_warning(string $message, array $context = []) void Logs unexpected conditions or deprecated feature usage.
log_warning('Rate limit nearing threshold', ['ip' => $ip]);
log_debug(string $message, array $context = []) void Records verbose diagnostic traces (only logged when APP_DEBUG=true in .env).
log_debug('SQL Query execution trace', ['time' => '1.2ms']);
Extending Global Helpers

You can define your own project-specific helper functions by creating a file in your project (e.g. App/helpers.php) and adding it to the "files" autoload array inside your composer.json.
