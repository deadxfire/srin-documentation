Controllers & Actions

Controllers in Srin Engine are clean, readable, and packed with built-in superpowers. By extending Core\BaseController, your classes gain instant access to input parsing, automatic type casting, flash sessions, validation, and secure downloads—without requiring excessive dependency injection or boilerplate.

Creating a Controller

Scaffold a new controller using the Srin CLI:

Bash 
php srin make:controller Article

This creates Controller/ArticleController.php:

PHP 
namespace Controller;

use Core\BaseController;
use Model\Article;

class ArticleController extends BaseController
{
    public function index(): string
    {
        $articles = Article::where('is_published', true)
            ->search('title', $this->get('q'))
            ->filter('category', $this->get('category'))
            ->latest()
            ->paginate(10);

        return $this->view('articles/index', [
            'articles' => $articles,
        ]);
    }
}

3. Session Flash Messages

Flash messages persist in the session for exactly one subsequent request—ideal for redirect feedback:

PHP 
// Method chaining with back() or redirect()
$this->flashSuccess('Article updated successfully!')
     ->redirectToRoute('articles.index');

// Available flash shortcuts:
$this->flashSuccess('Saved!');
$this->flashError('Something went wrong.');
$this->flashInfo('Please confirm your email.');
$this->flashWarning('Your session expires in 5 minutes.');

Display flash messages in your .srin.php view templates using the has_flash() and flash() helpers:

HTML / Srin Template 
<?php if (has_flash('success')): ?>
    <div class="alert alert-success">
        <?= flash('success') ?>
    </div>
<?php endif; ?>

4. Form Validation Engine

Validate incoming data using expressive pipe-delimited rule strings:

PHP 
public function store(): void
{
    $this->validateCsrf();

    $data = $this->onlyInputs(['title', 'email', 'category', 'password', 'password_confirmation']);

    $errors = $this->validate($data, [
        'title'    => 'required|min:5|max:150',
        'email'    => 'required|email',
        'category' => 'required|in:technology,design,lifestyle',
        'password' => 'required|min:8|confirmed',
    ]);

    if (!empty($errors)) {
        $this->flashError('Please fix the errors below.')
             ->back();
        return;
    }

    Article::create($data);
    $this->flashSuccess('Article published!')->redirectToRoute('articles.index');
}
Supported Validation Rules

required, email, numeric, url, min:N, max:N, alpha, alphanumeric, in:foo,bar, and confirmed (compares field with field_confirmation).

Srin Signature: The Action Guard ($this->guard())

Traditional frameworks force developers to write 20+ lines of repetitive ceremony for every form submission: checking rate limits, verifying CSRF tokens, checking bot honeypots, extracting only safe fields, validating, and checking error arrays to redirect back.

Srin Engine introduces the Action Guard ($this->guard())—a unified, single-line method that handles the entire pipeline:

PHP (Srin Signature Style) 
public function store()
{
    // 1. Verifies CSRF & Honeypot automatically on POST
    // 2. Extracts only whitelisted fields (defeats mass assignment)
    // 3. Enforces validation rules
    // 4. If invalid: auto-flashes error and redirects back!
    $data = $this->guard([
        'title'   => 'required|min:5|max:200',
        'slug'    => ['required', 'min:3'],
        'content' => 'required|min:20',
        'summary', 'price', 'is_published', // whitelisted optional fields
    ]);

    $article = Article::insert($data);

    return $this->success('Article published!')->go('articles.show', ['slug' => $article->slug]);
}

Handling File & Image Uploads

Srin Engine makes handling file and image uploads safe, effortless, and elegant. Through Core\BaseController and Core\Request, you can check for valid uploads, inspect file metadata, enforce strict extension whitelists, and store files safely with collision-resistant filenames.

1. HTML Form Requirements

When submitting files or images, ensure your HTML form includes enctype="multipart/form-data", method="POST", and Srin's CSRF token:

HTML / Srin Template 
<form action="<?= route('articles.store') ?>" method="POST" enctype="multipart/form-data">
    <?= csrf_field() ?>
    <?= honeypot_field() ?>

    <div class="form-group">
        <label for="title">Article Title</label>
        <input type="text" name="title" id="title" class="form-control" required>
    </div>

    <div class="form-group">
        <label for="cover">Cover Image</label>
        <input type="file" name="cover" id="cover" accept="image/*" class="form-control">
    </div>

    <button type="submit" class="btn btn-primary">Publish Article</button>
</form>

2. Checking & Storing Uploads in the Controller

In your controller, use $this->hasFile('key') to safely verify an upload without false positives from empty form submissions. Then, use $this->storeFile() to securely validate extensions and save the file:

PHP (Controller) 
namespace Controller;

use Core\BaseController;
use Model\Article;

class ArticleController extends BaseController
{
    public function store()
    {
        // 1. Guard inputs (verifies CSRF, honeypot, and validates text fields)
        $data = $this->guard([
            'title'    => 'required|min:5|max:200',
            'category' => 'required',
            'content'  => 'required|min:20',
        ]);

        // 2. Handle cover image upload safely
        if ($this->hasFile('cover')) {
            // Validates extension, generates unique 32-char hex name, and stores in assets/uploads/
            $imagePath = $this->storeFile('cover', 'assets/uploads', ['jpg', 'jpeg', 'png', 'webp']);
            
            if (!$imagePath) {
                return $this->fail('Invalid image format! Only JPG, PNG, and WebP are allowed.')->back();
            }

            $data['cover_image'] = $imagePath;
        }

        // 3. Persist model
        $article = Article::insert($data);

        return $this->success('Article and cover image uploaded successfully!')
            ->go('articles.show', ['slug' => $article->slug]);
    }
}

3. File Upload API Reference

Method Return Type Description & Behavior
$this->hasFile(string $key) bool Checks if a valid file was uploaded with UPLOAD_ERR_OK and a non-empty temporary file. Correctly returns false if the user submitted the form without picking a file (preventing UPLOAD_ERR_NO_FILE bugs).
$this->file(string $key) ?array Returns the raw $_FILES[$key] associative array with keys: name, type, tmp_name, error, and size. Returns null if key is missing.
$this->files() array Returns the entire $_FILES array, useful for iterating over multiple or dynamic file upload fields.
$this->storeFile(string $key, string $destinationDir, array $allowedExtensions) ?string Moves the uploaded file to target directory (defaults to assets/uploads). Automatically enforces extension whitelisting, prevents directory traversal, generates a cryptographically random filename (bin2hex(random_bytes(16))), creates the directory if missing, and returns the stored relative web path or null on failure.

4. Displaying Uploaded Images in Views

Once stored in assets/uploads/, render the image in any template using Srin's assets() helper:

HTML / Srin Template 
<?php if (!empty($article->cover_image)): ?>
    <img src="<?= assets($article->cover_image) ?>" alt="<?= e($article->title) ?>" class="img-fluid rounded">
<?php else: ?>
    <img src="<?= assets('images/default-cover.jpg') ?>" alt="Default Cover">
<?php endif; ?>
