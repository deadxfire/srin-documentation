Templates, Layouts & Slots

Srin Engine features a modern, ultra-clean template compiler supporting .srin.php files. To break away from repetitive framework clichés and verbose copycat syntax (like Laravel Blade's @if and @foreach), Srin Engine introduces Srin Tags ([if], [each], [empty], [ifend], [eachend], [blockend])—an intuitive, tag-based templating system with zero shift-key friction and crystal-clear named block closures.

The Srin Signature: Clean Tag Templating & Named Closers

Notice the difference immediately: no cluttered @ prefixes, no ambiguity about which block is closing when nested. Srin gives you descriptive named closers ([ifend], [eachend], [blockend], [endless]) as well as HTML-style slash closers ([/if], [/each], [/block]) or universal [end]:

HTML / Srin Template (Pages/blog/index.srin.php) 
[layout 'layouts/app']
[title 'Latest Articles']

<section class="hero mb-5">
    <h1>Welcome to Our Blog</h1>
    <p>Discover stories and insights built with Srin Engine.</p>
</section>

<div class="row">
    [each $posts as $post]
        <div class="col-md-6 mb-4">
            <div class="card h-100 shadow-sm">
                [if !empty($post->cover_image)]
                    <img src="[[ assets($post->cover_image) ]]" class="card-img-top" alt="[[ $post->title ]]">
                [ifend]
                <div class="card-body">
                    <h2>[[ $post->title ]]</h2>
                    <p>[[ $post->summary ]]</p>
                    <a href="[[ route('blog.show', ['slug' => $post->slug]) ]]" class="btn btn-outline-primary">Read More →</a>
                </div>
            </div>
        </div>
    [empty]
        <div class="col-12 text-center py-5">
            <p class="text-muted">No articles published yet. Check back soon!</p>
        </div>
    [eachend]
</div>

[paginate $posts]

Zero Laravel Copycat: Syntax Comparison

Laravel Blade (Old & Verbose) Srin Tags (Modern & Clean) Why Srin Tags Are Superior
@if($user) ... @endif [if $user] ... [ifend] (or [/if]) No @ prefix; dedicated [ifend] or HTML-style [/if] prevents nesting confusion.
@foreach($items as $i) ... @endforeach [each $items as $i] ... [eachend] (or [/each]) Natural English verb each closed cleanly with [eachend].
@forelse(...) ... @empty ... @endforelse [each $items as $i] ... [empty] ... [eachend] No need to switch between foreach and forelse! Just drop in [empty] whenever needed.
@unless($user) ... @endunless [unless $user] ... [endless] (or [unlessend]) Catchy, intuitive [endless] or [unlessend] closer.
@csrf [csrf] Clean bracket tag matching your HTML component structure.
@honeypot [honeypot] Renders anti-bot security trap field seamlessly.
@extends('layout') [layout 'layouts/app'] Direct, intuitive declaration at the top of your page.
@section('scripts') ... @endsection [block 'scripts'] ... [blockend] (or [/block]) Concise block definition with explicit [blockend].
@yield('scripts') [slot 'scripts'] Component-like slot system with optional default values: [slot 'scripts', '/* fallback */'].

Layouts, Slots & Blockincludes

Master layouts live in Pages/layouts/. You can define where the child page content goes using either [blockinclude 'main'], [slot 'main'], or generic [blockinclude] / [slot]:

HTML / Srin Layout (Pages/layouts/app.srin.php) 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>[[ $title ?? 'Srin Application' ]]</title>
    <link rel="stylesheet" href="[[ assets('css/app.css') ]]">
    [blockinclude 'head']
</head>
<body>
    [include 'partials/navbar']

    <main class="container py-4">
        <!-- Renders child page [block 'main'] or direct page body -->
        [blockinclude 'main']
    </main>

    [include 'partials/footer']

    <script src="[[ assets('js/app.js') ]]"></script>
    [blockinclude 'scripts']
</body>
</html>

Dynamic Titles & Page Connection

Connect child pages to a layout using [connect 'layouts/app'] (or [connect 'app']). You can set the title using dynamic PHP expressions:

HTML / Srin Template (Dynamic Title) 
[connect 'layouts/main']
<!-- Dynamic PHP expression evaluated with controller data -->
[title $post->title . ' - SrinBlog']

<!-- Or using a dedicated title block if preferred -->
[block 'title']
    [[ $post->title ]] - SrinBlog
[blockend]

Injecting Named Blocks with [block]

When a page needs to push custom content, scripts, or styles into layout slots, define [block 'name'] ... [blockend]:

HTML / Srin Template 
[connect 'layouts/app']
[title 'Interactive Dashboard']

[block 'main']
<h1>Sales Dashboard</h1>
<canvas id="analyticsChart"></canvas>
[blockend]

[block 'scripts']
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
<script>
    const ctx = document.getElementById('analyticsChart');
    new Chart(ctx, { /* chart config */ });
</script>
[blockend]

Full Srin Tags Reference

Tag / Syntax Behavior Description
[if $condition] ... [ifend] (or [/if]) Standard conditional rendering. Also supports [elseif $condition] and [else]. Universal [end] also accepted.
[each $items as $item] ... [eachend] (or [/each]) Loop over arrays, models, or iterators. Supports key-value pairs ([each $map as $k => $v]).
[empty] Placed inside [each] to render fallback content if collection is empty.
[unless $condition] ... [endless] (or [unlessend], [/unless]) Inverse conditional (renders if condition is falsy).
[isset $var] ... [issetend] (or [/isset]) Checks if a variable is set and not null.
[for $i = 0; $i < 5; $i++] ... [forend] (or [/for]) Standard numeric for loop.
[while $condition] ... [whileend] (or [/while]) While loop evaluation.
[csrf] Renders hidden _csrf token input field for secure POST forms.
[honeypot] Renders invisible anti-bot honeypot trap.
[include 'partials/card'] Includes a partial template. Optional data: [include 'card', ['item' => $post]].
[flash 'success'] Renders styled alert block if the session contains a flash message for that key.
[paginate $posts] Renders full, accessible pagination navigation bar.
[[ $var ]] Evaluates PHP expression and auto-escapes output with htmlspecialchars. Zero collision with Vue.js/Alpine.js!
[{ $html }] Renders raw, unescaped HTML output (for trusted rich text, markdown, etc.).
[-- comment --] Server-side comment, completely stripped and omitted from HTML source code.
[end] Universal fallback closer supported on any block type for developers who prefer shorthand.
Strict Blade Isolation

To preserve Srin Engine's identity, raw speed, and pure architecture, Laravel Blade directives (@if, @foreach, @include, @section) are strictly blocked and will throw a descriptive compilation exception. Always use Srin Tags.
