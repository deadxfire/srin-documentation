Mail Transfer & SMTP

Srin Engine features a versatile email subsystem powered by PHPMailer with fallback to native PHP mail and a local log driver that writes outgoing messages to disk during local development.

Mail Configuration

Configure your email credentials in Config/mail.php and provide values via .env:

.env 
# Mail Driver: "smtp", "log", or "mail"
MAIL_DRIVER=smtp

# SMTP Credentials
MAIL_HOST=smtp.mailgun.org
MAIL_PORT=587
MAIL_USERNAME=postmaster@your-domain.com
MAIL_PASSWORD=secret_smtp_password
MAIL_ENCRYPTION=tls

# Default Sender Identity
MAIL_FROM_ADDRESS=noreply@your-domain.com
MAIL_FROM_NAME="Srin Engine Notification"
Local Development with the 'log' Driver

Set MAIL_DRIVER=log while developing locally. Instead of attempting to connect to external SMTP servers, outgoing emails are recorded directly into Storage/logs/mail.log, complete with headers, recipients, and HTML content.

Sending an Email

Use the Core\Mailer::send() method or the global mail_send() helper:

PHP (Controller/ContactController.php) 
namespace Controller;

use Core\BaseController;
use Core\Mailer;

class ContactController extends BaseController
{
    public function submit(): void
    {
        $this->validateCsrf();
        $this->validateHoneypot();
        $this->rateLimit('contact-form', maxAttempts: 3, decaySeconds: 120);

        $name    = $this->post('name');
        $email   = $this->post('email');
        $message = $this->post('message');

        $result = Mailer::send([
            'to'         => 'support@example.com',
            'subject'    => "New Inquiry from {$name}",
            'body'       => nl2br(htmlspecialchars($message, ENT_QUOTES, 'UTF-8')),
            'reply_to'   => $email,
            'reply_name' => $name,
            'is_html'    => true,
        ]);

        if ($result['success']) {
            $this->flashSuccess('Your message has been sent successfully!')
                 ->back();
        } else {
            $this->flashError('Unable to send message: ' . $result['message'])
                 ->back();
        }
    }
}

Mailer Options Reference

Option Key Type Description
to string Recipient email address (Required).
subject string Email subject line.
body string Body content (HTML or plain text).
is_html bool Defaults to true. Set false for plain-text email.
from string Sender email address (falls back to MAIL_FROM_ADDRESS).
from_name string Sender display name (falls back to MAIL_FROM_NAME).
reply_to string Optional Reply-To email address.
reply_name string Optional Reply-To display name.

CLI Scaffolding with --mail

Srin CLI can automatically scaffold contact controllers pre-wired with validation and mail sending logic:

Bash 
php srin make:controller Contact --mail
