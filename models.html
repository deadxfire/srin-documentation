ActiveRecord Models & CRUD

Srin Engine features an elegant ActiveRecord ORM implementation. Every database table maps directly to a Model class, allowing you to query, insert, update, and manage records with clean, expressive object-oriented syntax.

Defining a Model

Generate a new model using the Srin CLI:

Bash 
# Generate model
srin add model Post

# Or generate model with its schema migration
srin add model Post -m

Here is a typical Srin Model definition located in Model/Post.php:

PHP (Model/Post.php) 
namespace Model;

use Core\Model;

class Post extends Model
{
    /**
     * The table associated with the model (optional).
     * If omitted, Srin pluralizes the class name (e.g. 'posts').
     */
    protected string $table = 'posts';

    /**
     * The primary key column name (defaults to 'id').
     */
    protected string $primaryKey = 'id';

    /**
     * The attributes that are mass-assignable.
     */
    protected array $fillable = [
        'title',
        'slug',
        'category',
        'content',
        'is_published',
    ];

    /**
     * Indicates if the model should be timestamped.
     * Automatically sets created_at and updated_at.
     */
    protected bool $timestamps = true;
}

Srin Signature Model Verbs

Instead of verbose chaining and boilerplate ceremonies, Srin Engine provides clean, distinct standalone verbs:

Srin Signature Verb Conventional Verb Example Usage
Article::fetch(array $criteria) Article::where(...)->get() Article::fetch(['is_published' => true, 'status' => 'published'])->latest()
Article::one(array|string|int $criteria) Article::where(...)->firstOrFail() $article = Article::one(['slug' => $slug]); // Auto 404 if missing
Article::pick(int|string $id) Article::findOrFail($id) $article = Article::pick(42);
Article::insert(array $data) Article::create($data) $article = Article::insert($data);
Article::modify($id, array $data) Article::find($id)->update($data) Article::modify($id, ['title' => 'Updated']);
Article::remove($id) Article::destroy($id) Article::remove(42);
$article->hit(string $column) $article->col += 1; $article->save(); $article->hit('views'); // Atomic counter increment
Article::page(int $perPage, array $criteria) where(...)->paginate($perPage) Article::page(10, ['is_published' => true]);
Article::values(string $column, array $criteria) where(...)->distinctValues($column) Article::values('category', ['is_published' => true]);

Creating Records

Insert new rows into the database using create() or by instantiating the model and calling save():

Method 1: Mass Assignment via create()

PHP 
$post = Post::create([
    'title'        => 'Mastering Srin Engine',
    'slug'         => 'mastering-srin-engine',
    'category'     => 'development',
    'content'      => 'A deep dive into Srin Engine superpowers.',
    'is_published' => true,
]);

// Access newly generated ID
echo $post->id;

Method 2: Instantiation & save()

PHP 
$post = new Post();
$post->title = 'Another Great Article';
$post->category = 'tutorials';
$post->save();

Reading & Querying Records

PHP 
// Find a record by its primary key
$post = Post::find(1);

// Find or abort with 404 error if not found
$post = Post::findOrFail(99);

// Retrieve all records in the table
$allPosts = Post::all();

// Query with constraints
$popular = Post::where('views', '>', 1000)
    ->where('is_published', true)
    ->latest()
    ->get();

// Find the first matching record
$article = Post::where('slug', 'my-post')->first();

// First or Create
$tag = Tag::firstOrCreate(['name' => 'php']);

Updating Records

PHP 
// Find and mutate properties
$post = Post::find(1);
$post->title = 'Updated Title';
$post->views += 1;
$post->save();

// Or mass update using an array
$post->update([
    'category'     => 'news',
    'is_published' => false,
]);

Aggregates & Atomic Counters

Compute SQL calculations at the database engine level with zero memory overhead, and atomically increment or decrement numeric columns:

PHP 
// 1. Database-Level SQL Aggregates
$totalSales = Order::sum('amount');
$avgRating  = Review::avg('rating');
$minPrice   = Product::min('price');
$maxPrice   = Product::max('price');

// 2. Atomic Column Increment & Decrement
$article = Article::find(1);
$article->increment('views');        // Increments by 1 atomically
$article->increment('views', 5);     // Increments by 5
$product->decrement('stock', 2);     // Decrements by 2

// 3. Srin Hit Shortcut:
$article->hit('views');              // Expressive shortcut for increment('views', 1)

Deleting Records

PHP 
// Delete an existing model instance
$post = Post::find(1);
$post->delete();

// Or delete by primary key directly
Post::destroy(42);

// Delete records via query
Post::where('is_published', false)->delete();

Serialization: Array & JSON

Easily convert models to native PHP arrays or JSON strings for API responses:

PHP 
$post = Post::find(1);

// Convert to associative array
$arrayData = $post->toArray();

// Convert to JSON string
$jsonString = $post->toJson();
